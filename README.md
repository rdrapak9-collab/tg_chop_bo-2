# 🛍 Telegram-бот для магазину

Готовий бот на Python (aiogram 3): каталог товарів, кошик, оформлення
замовлення з оплатою на картку ПУМБ, підтвердження оплати адміном,
історія замовлень, прості адмін-команди для керування товарами.

---

## КРОК 1. Отримати токен бота

1. Відкрийте Telegram, знайдіть **@BotFather**.
2. Надішліть команду `/newbot`.
3. Вкажіть ім'я бота (наприклад, "Мій Магазин") та юзернейм, який
   обов'язково закінчується на `bot` (наприклад, `my_shop_bot`).
4. BotFather видасть токен — рядок виду
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxx`. Збережіть його.

## КРОК 2. Дізнатись свій Telegram ID

1. Знайдіть у Telegram бота **@userinfobot**.
2. Натисніть `/start` — він покаже ваш ID (число).
3. Збережіть це число — саме на нього бот надсилатиме сповіщення
   про нові замовлення.

## КРОК 3. Налаштувати проєкт локально

```bash
# Перейдіть у папку проєкту
cd tg_shop_bot

# Скопіюйте приклад налаштувань
cp .env.example .env
```

Відкрийте файл `.env` і заповніть:

```
BOT_TOKEN=ваш_токен_від_BotFather
ADMIN_IDS=ваш_telegram_id
CARD_NUMBER=1234 5678 9012 3456
CARD_HOLDER=Ім'я Прізвище
BANK_NAME=ПУМБ
SHOP_NAME=Назва Вашого Магазину
```

## КРОК 4. Встановити залежності та запустити локально (для тесту)

```bash
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

Якщо все правильно — у консолі з'явиться "Бот запускається..." і бот
почне відповідати в Telegram. Напишіть йому `/start`.

**Важливо:** поки цей процес запущений на вашому комп'ютері — бот
працює. Якщо закрити термінал або вимкнути ноутбук — бот вимкнеться.
Щоб він працював 24/7, потрібен хостинг (крок 6).

## КРОК 5. Додати перші товари

Напишіть боту в Telegram (з акаунту, ID якого ви вказали в ADMIN_IDS):

```
/admin
```

Це покаже список адмін-команд. Щоб додати товар:

```
/add_product
```

Бот запитає по черзі: категорію → назву → опис → ціну → фото.
Просто відповідайте текстом/фото на кожне питання.

Інші корисні команди:
- `/list_products` — список усіх товарів з їхніми ID
- `/remove_product 5` — прибрати товар з ID=5 з продажу
- `/orders` — показати замовлення, що очікують перевірки оплати

## КРОК 6. Запустити бота 24/7 (хостинг)

Локальний запуск підходить тільки для тестування. Для реальної
роботи бот повинен бути на сервері. Ось найпростіший безкоштовний
варіант:

### Railway.app (рекомендовано, є безкоштовний ліміт)

1. Зареєструйтесь на [railway.app](https://railway.app) через GitHub.
2. Завантажте цей проєкт до свого GitHub-репозиторію.
3. У Railway натисніть **New Project → Deploy from GitHub repo**,
   виберіть репозиторій із ботом.
4. У розділі **Variables** додайте ті самі змінні, що й у `.env`:
   `BOT_TOKEN`, `ADMIN_IDS`, `CARD_NUMBER`, `CARD_HOLDER`, `BANK_NAME`, `SHOP_NAME`.
5. Railway автоматично встановить залежності з `requirements.txt`
   і запустить `python bot.py`. Якщо потрібно — додайте файл
   `Procfile` з вмістом `worker: python bot.py`.
6. Бот запуститься і працюватиме цілодобово, поки активний проєкт.

**Важливо про базу даних на Railway:** файлова система там може
скидатись при передеплої. Якщо це критично — підключіть Railway
PostgreSQL (безкоштовний план) замість SQLite, або тримайте це на
VPS (варіант нижче), де файли зберігаються постійно.

### Альтернатива: власний VPS (більше контролю, від ~$3-5/міс)

Підходить, якщо товарів багато і плануєте активно розвивати бота.
Наприклад, DigitalOcean, Hetzner, або український хостинг.

Коротко:
```bash
# на сервері (Ubuntu)
sudo apt update && sudo apt install python3-pip python3-venv git -y
git clone <ваш_репозиторій>
cd tg_shop_bot
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env    # і заповнити

# щоб бот працював навіть після виходу з сервера, використайте screen або systemd:
screen -S bot
python bot.py
# Ctrl+A потім D, щоб "відв'язатись" і лишити бота працювати
```

Для надійнішого запуску краще налаштувати `systemd`-сервіс, щоб бот
автоматично перезапускався при збоях чи перезавантаженні сервера —
я можу допомогти це налаштувати, якщо оберете цей варіант.

## Способи оплати: картка ПУМБ, польські реквізити, Apple Pay

Бот тепер вміє пропонувати клієнту вибір способу оплати:

1. **💳 Картка ПУМБ** — працює одразу, реквізити беруться з `.env`
   (`CARD_NUMBER`, `CARD_HOLDER`).

2. **🇵🇱 Польський переказ/BLIK** — з'являється автоматично, щойно ви
   заповните в `.env` хоча б одне з полів `PL_ACCOUNT_NUMBER` або
   `PL_BLIK_PHONE`. Якщо залишити порожнім — кнопка просто не
   показуватиметься клієнтам.

3. **🍏 Apple Pay / картка онлайн** — це справжня оплата карткою прямо
   в Telegram (на iPhone Telegram сам показує кнопку Apple Pay, якщо
   пристрій це підтримує). Це офіційна функція Telegram Payments, а
   не імітація — гроші проходять через платіжного провайдера
   (найпростіше — Stripe).

   **Як підключити (займає ~10-15 хвилин):**
   1. Зареєструйтесь на [stripe.com](https://stripe.com) (потрібні
      дані компанії/ФОП для виведення грошей; для тестування можна
      користуватись тестовим режимом без реєстрації бізнесу).
   2. У Telegram напишіть **@BotFather** → `/mybots` → оберіть свого
      бота → **Payments** → оберіть **Stripe** → виконайте авторизацію
      свого Stripe-акаунту.
   3. BotFather видасть **provider token** — довгий рядок символів.
   4. Вставте його в `.env`:
      ```
      PAYMENT_PROVIDER_TOKEN=ваш_токен_від_stripe
      ```
   5. Перезапустіть бота — кнопка "🍏 Apple Pay / Картка онлайн"
      з'явиться автоматично при оформленні замовлення.

   Поки `PAYMENT_PROVIDER_TOKEN` не заповнено — ця кнопка прихована,
   і клієнти бачитимуть лише готівкові способи (ПУМБ / польські
   реквізити), нічого не зламається.

   **Важливо:** оплата через цей спосіб списується в **злотих**
   (курс бот бере той самий, що показує в цінах). Коли Stripe буде
   готовий приймати гривню напряму — можна буде переключити валюту
   рахунку на UAH у коді (`currency="UAH"` замість `"PLN"` в
   `bot.py`, функція `pay_method_card`).



1. `/start` → бачить меню: Каталог, Кошик, Мої замовлення
2. Обирає товари → "Додати в кошик"
3. У кошику може змінювати кількість або видаляти товари
4. "Оформити замовлення" → вказує телефон і спосіб доставки
5. Бачить реквізити картки ПУМБ → переказує гроші → надсилає скріншот
6. Ви отримуєте сповіщення з фото чеку і кнопками "Підтвердити"/"Відхилити"
7. Клієнт одразу отримує повідомлення про статус
